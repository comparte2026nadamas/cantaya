# CantaYa Karaoke

Karaoke web con YouTube: la laptop/TV es la pantalla y cada celular se convierte en micrófono por WiFi (WebRTC). Incluye calificación de cada canción y ranking de la noche.

- `src/app.html` + `src/app.js`: código fuente.
- `node build.js`: genera `dist/index.html` (un solo archivo con todo incluido).
- `dist/`: lo que publica Netlify.
